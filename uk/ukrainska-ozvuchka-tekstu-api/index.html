Українська озвучка тексту через API - природні голоси, MP3 і субтитри

Як одним викликом API перетворити український текст, статтю чи файл DOCX/PDF на природне мовлення - три українські нейроголоси, MP3 і SRT, справжній запуск, який можна послухати, ціна та обмеження.

Добрих українських голосів у сервісах синтезу мовлення мало: багато сервісів їх не мають зовсім, а відкриті голоси часто ставлять наголос не туди. Тут - один виклик API, що перетворює український текст на MP3 із субтитрами, і зразок, який можна прослухати просто на цій сторінці. Запуск - 7 листопада 2026 року.

Розкриття: інструмент, про який ідеться, - Text to Speech на Apify - зробив я. Голоси працюють усередині нього (нейромоделі Piper), тож жодного іншого сервісу чи вашого ключа не потрібно. Код відкритий: AndriyVK/-apify-document-tools.

Спершу послухайте

Голос uk_UA-tetiana-high, швидкість 1.12, MP3. Це файл саме такий, яким його повернув API, без обробки.

Виклик

from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("ai_admin/text-to-speech").call(run_input={
    "text": "Добрий день! Це український голос, створений нейромережею.\n\n"
            "Він читає статті, документи та субтитри природно і без акценту.",
    "voice": "uk_UA-tetiana-high",   # або uk_UA-mykyta-high, uk_UA-oleksa-high
    "speed": 1.12,
    "format": "mp3",                 # mp3, wav або ogg
    "subtitles": True,               # SRT і VTT, безкоштовно
})
item = next(client.dataset(run["defaultDatasetId"]).iterate_items())
print(item["durationSeconds"], item["audioUrl"], item["srtUrl"])

Замість text можна передати sources - посилання на файли TXT, Markdown, HTML, DOCX чи PDF (з текстовим шаром), по одному аудіофайлу на кожен.

Увесь запуск зайняв 30 секунд, переважно запуск контейнера. Орієнтир: 750-900 знаків - це хвилина мовлення.

Ціна

За кожну розпочату хвилину звуку: $40 за 1000 хвилин для голосів high (4 центи за хвилину) і $10 за 1000 для голосів medium/low. Усі три українські голоси - high. Зразок вище - одна розпочата хвилина, 4 центи. Субтитри безкоштовні.

Обмеження

  • Числа, скорочення й іншомовні слова читаються за правилами голосу і можуть звучати дивно: пишіть «двадцять п'ять» або перевіряйте, як звучить «25».
  • Скановані PDF без текстового шару не читаються - спершу OCR (див. Скани українською - у Markdown).
  • Це синтезований голос. Для чернетки аудіокниги чи доступності - добре; для фінального релізу професійний диктор поки кращий.
