Translate TikTok, Reels, Facebook and YouTube videos into Ukrainian and 20 more languages - transcript and SRT subtitles by API

One API call turns a video link from TikTok, Instagram Reels, Facebook, X or YouTube into a transcript and translated SRT/VTT subtitles in Ukrainian or 20 other languages - even when the video has no captions. Real runs, the output, and what the most used transcript Actors can and cannot do.

Getting the text of a video is easy today. Getting it translated, with subtitles timed to the video, for a TikTok or a Reel without captions is where most tools stop. This post shows a tool that does the whole chain in one call: download, speech recognition, translation and subtitle files. Every output below is from real runs on 16 November 2026.

Disclosure: I built the tool, Video Transcript & Translation on Apify. The code is open: AndriyVK/-apify-document-tools.

One call

from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("ai_admin/social-video-transcript").call(run_input={
    "videoUrls": [
        "https://www.tiktok.com/@nasa/video/7698805564884733198",
        "https://www.facebook.com/NASA/videos/360-degree-view-from-the-cupola/346691430131/",
    ],
    "translateTo": "uk",
})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item["title"], item["translation"]["srtUrl"])

And it handles five platforms in one list of links, where most of them handle one.

What that means in practice:

  1. Translation for every platform, into Ukrainian and 20 more languages. The tools that translate at all either work only on YouTube and only when YouTube itself can translate the captions, or translate only into English. Of the Instagram and TikTok tools in the table, only one translates, and only into English.
  2. Translated subtitles, not just text. Ukrainian SRT and VTT files with the original timing, ready for a video editor or a player.
  3. All platforms in one tool. One list of links can mix YouTube, TikTok, Reels, Facebook and X. Most alternatives handle one platform.
  4. Works when there are no captions. The speech is recognised with Whisper large-v3; caption-only YouTube tools return nothing for such videos.
  5. Missed speech is checked for free. Every transcript is checked for stretches where speech was skipped, and those places are recognised again.
  6. Failed videos are free. A private or deleted video gets an error and is not charged.
  7. No API key of your own. No OpenAI or other account - you pay per video through Apify.

For noisy recordings there is also an optional cross-check: the audio is recognised by a second model and the places where the two disagree are listed, figures first (recognition is then charged twice).
